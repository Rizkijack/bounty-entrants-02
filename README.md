Two bounties of our own, launched through make.fun's sponsor flow: a 120-word cold-email contest judged by an AI playing a busy plumber, and a treasure-map drawing contest judged on charm. Each charges a $0.50 entry fee. This repository hands in their addresses in BOUNTY.json — the house counts their paying entrants, and the most entrants wins a share of $250.

## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```
